How it works

  1. Create a folder

    In FriendsShare, click New and name the folder, or use a folder you already have. Put the files you want to share inside.

  2. Send the code

    Click Generate code and send the code to your friend, in Discord, by email or any other way. You choose how long it works, from 1 to 365 days.

  3. Your friend downloads

    They click Add code and paste it. They see the file list, tick what they want and click Download selected. Later changes sync by themselves.

Both of you need the app, and both PCs have to be on while files move. That is the price of never storing them on a server.

Where your files go

From your PC to your friend's PC, and nowhere else.

  • Direct and encrypted. The two apps open a direct, encrypted connection. Your files are never uploaded to a server or stored on one.
  • The server only introduces. A small matchmaking server tells the two apps how to find each other. It sees a scrambled fingerprint (SHA-256) of the code and the connection handshake. It never sees the code, the file names or the files.
  • One thing to know. Because the two PCs connect directly, they see each other's IP address, as in any direct connection.

All the details are on the privacy page.

Questions and answers

Is there a size limit?

No. FriendsShare puts no limit on the size of a file or a folder, on any plan. Files go straight from one PC to the other and are never stored on a server, so there is no storage to run out of. How fast it goes depends on both internet connections.

Do we both need to be online?

Yes. Both PCs have to be on, with FriendsShare running, while files move. The app sits in the tray, and starting it with Windows is optional, so it can stay running in the background. Nothing is stored on a server, so there is nothing to download while the sharing PC is off.

What does the server see?

The server only introduces the two apps to each other. It sees a scrambled fingerprint (a SHA-256 hash) of the share code and the connection handshake, plus your IP address and the app version while the app is connected. It never sees the share code itself, the file names or the files. The two PCs also see each other's IP address, as in any direct connection.

Windows says "Windows protected your PC". What do I do?

Windows shows this for apps it does not know yet. FriendsShare is not code-signed yet, so Windows cannot tell who made it. Click More info, then Run anyway. Only do this for a copy you downloaded from this site or from the FriendsShare releases on GitHub. The source code is public if you want to check what the app does.

It cannot connect. What now?

First check that both PCs are on, both apps are running, and the code has not expired or been replaced. If that is fine, the cause is usually the network. A few strict networks block direct connections: some mobile hotspots, and some university or company networks. If both of you are on such a network, FriendsShare cannot connect you. There is deliberately no relay server, because a relay would mean your files pass through a server. Switching one of the two PCs to another network, for example home Wi-Fi, usually solves it.

Is there a version for Mac or Linux?

Not at the moment. FriendsShare runs on Windows 10 and 11 (64-bit) only for now. Both you and your friend need the app, so both of you need Windows.

What counts as a folder?

On the Free plan you can have up to {{free_limit}} folders at a time. Every folder you share and every folder you received from a friend counts. Remove one to free a slot. Removing a folder from FriendsShare never deletes any files.

What happens when Pro ends?

Pro runs to the end of the period you paid for. After that your account is on the Free plan: the first {{free_limit}} folders keep working and the rest are paused. Nothing is deleted.

How do I cancel Pro?

Sign in, open your account and click Manage subscription. That opens a page on Stripe where you can cancel. Pro then keeps running until the end of the period you paid for.

Is it open source?

The source code is public on GitHub, but the license is PolyForm Noncommercial. That is source-available rather than open source in the strict sense. You can read, run and change it for personal, noncommercial use. Commercial use is reserved to the author. A copy you build yourself cannot use the official server, but you can run your own.
